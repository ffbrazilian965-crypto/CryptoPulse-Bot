# CryptoPulse Bot

A Telegram bot that provides crypto trading signals, whale alerts, and market sentiment using the CoinGecko API.

## Features
- Crypto trading signals
- Whale alerts
- Market sentiment analysis
- Real-time data from CoinGecko API

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Set your Telegram bot token and run:
   ```bash
   python main.py
   ```

## Requirements
- Python 3.7+
- pyTelegramBotAPI
- requests
